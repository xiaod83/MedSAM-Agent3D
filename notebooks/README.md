# Optional notebooks

- `colab.ipynb`: open in Google Colab for remote GPU execution.
- `colab_runner.py`: matching cell-by-cell Python source; intended for Colab.

For local commands, return to the root folder and use `run.py`. These files are not local application entry points.

Build a source ZIP for the notebook with `python run.py bundle`. It is written under `outputs/bundles/`.
